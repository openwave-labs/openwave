## 3. The state behind the 0.83

You asked that this post say plainly what the deposited 0.83 is and which gates it fails.

**It is out of configuration by the plan's own rule.** The rule frozen before the run asks for degree 1 of the long axis on the spheres r = 3 and r = 4. On the J_e/10 state the degree is 0 on both, 0.01 at r = 5 (where the two larger eigenvalues nearly meet, gap 0.008) and 1 only at r = 5.7. The deposited J = 0 state reads the same on r = 3 and r = 4. So the object relaxed in this box is not a hedgehog of the long axis inside r = 4, and the 0.83 is a number of that object. Section 8 shows that this holds for every state of the run with fixed faces and L₁ > 0 at δ = 0.3, on every box.

**It is a local minimum of the discrete energy, and a lower stationary state exists.** The lowest Hessian eigenvalue is +1.13 × 10⁻³ (gate 5). The one-cell state of section 2 lies 5.88 below it on the forward stencil; on the mirror-averaged stencil the one-cell state lies 4.9, 8.0 and 9.9 below the smooth state at spacings 0.375, 0.25 and 0.1875.

**Its ratio is set by the box** (section 4). That is measured on the mirror-averaged ladder with the chart fixed, whose half-box 6 rung reads 0.839; the forward stencil on your frame was run on half-box 6 only.
