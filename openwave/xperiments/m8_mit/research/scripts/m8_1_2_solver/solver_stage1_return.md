## Item 13: derivation of w_K

1. Row section psi(g) = u^T D^3(g) eta, P = eta eta^dag. Then |psi(g)|^2 = sum u_m conj(u_m') P_nn' D_mn(g) conj(D_m'n'(g)).
2. conj(D^j_{m'n'}) = (-1)^{m'-n'} D^j_{-m',-n'}, equivalent to Theta D = D Theta; verified exactly for the matrices used, at the generators.
3. Clebsch-Gordan series: D^j_{mn} D^j_{m''n''} = sum_K <j m; j m''|K M><j n; j n''|K N> D^K_{MN}.
4. Put m'' = -m', n'' = -n'. The sums collapse into the transform of Section 2.3 on both sides:

```text
|psi(g)|^2 = sum_K  rho_K(u)^T  D^K(g)  R_K ,   rho_K(u) = M_K(u u^dag),  R_K = M_K(P)
```

   Checked exactly at g = (1 + 2i + 2j + 4k)/5 with a random Gaussian-rational u, in both sectors.
5. Right Gamma-invariance of |psi|^2 (or equivariance of M_K with [P, D(h)] = 0) puts R_K in (V_K)^Gamma, so R_K = 0 for K = 1..5 (item 10).
6. For a right-Gamma-invariant function, the normalised measure on X equals normalised Haar measure on SU(2). Schur orthogonality, int D^K_{MN} conj(D^K'_{M'N'}) = delta delta delta/(2K+1), gives

```text
B = rho_0 R_0 = (-||u||^2/sqrt7)(-d/sqrt7) = d ||u||^2 / 7
A = int |psi|^2 conj(|psi|^2) = sum_K ||rho_K(u)||^2 ||R_K||^2 / (2K+1)
Q_d = A / B^2 = sum_K [ 49 ||R_K||^2 / ((2K+1) d^2) ] * ||rho_K||^2 / ||u||^4
```

7. Hence w_K = 49 ||R_K||^2/((2K+1) d^2). R_0 = -d/sqrt7 gives ||R_0||^2 = d^2/7 and w_0 = 7 for every d. With rhat_0 = 1/7 (exact), the K = 0 term is 1, so Q_d = 1 + w_6 rhat_6.
8. FLOAT cross-check: Euler-angle quadrature (28^3 nodes, Gauss-Legendre in cos beta) reproduces B and A to 1e-15 relative in both sectors (`solver_crosscheck_quadrature.py`).

⚠️ Underdetermination found: sum_K rhat_K = 1 identically, because the CG decomposition of

equivariant projection onto V_8" to be Pi_8, the canonical V_8-isotypic projection, and
C(u) = Pi_8(u (x) Theta u (x) u). Step 0 shows that this reading and the other natural one,
C_0(u) = [[u (x) u]_6 (x) Theta u]_8, have the same zero set. Scale plays no role.

**Theorem.** For u nonzero in V_3: C(u) = 0 if and only if Theta u = lambda u for some lambda
with |lambda| = 1. Equivalently, [u] is time-reversal invariant, u is in U(1) Fix(Theta), and
(Section 2.2) the six Majorana points are antipodally symmetric as a multiset.

**Proof.**

0. *Reduction to one coupling.* Let tau swap tensor slots 1 and 3. x = u (x) Theta u (x) u is
tau-fixed. tau is SU(2)-equivariant, so it commutes with Pi_8 and Pi_8 x lies in the
V_8-isotypic part of W = (V_3^(x3))^tau, which is Sym^2 V_3 (x) V_3 (slots {1,3} and 2).
Sym^2 V_3 = V_6 + V_4 + V_2 + V_0, and V_L (x) V_3 contains V_8 only for L >= 5. So W contains V_8
exactly once (item 2: dim Hom(Sym^2 V_3 (x) conj V_3, V_8) = 1). Hence Pi_8 x = 0 iff phi(x) = 0
for the unique-up-to-scale nonzero equivariant map phi: W -> V_8, and phi(x) is a nonzero multiple
of C_0(u) = [B_6(u) (x) Theta u]_8. Computed confirmation: in the orthonormal coupled basis the
components of Pi_8 x are [[u (x) Theta u]_5 (x) u]_8 = (sqrt3/2) C_0(u) and
[[u (x) Theta u]_6 (x) u]_8 = (-1/2) C_0(u), so ||Pi_8 x|| = ||C_0(u)|| exactly.

1. *Binary forms.* iota_j(v_m) = x^(j+m) y^(j-m)/sqrt((j+m)!(j-m)!) is an SU(2)-equivariant
linear isomorphism of V_j onto the forms of degree 2j (it is how D^j is defined here).
Multiplication of forms is equivariant, bilinear and nonzero, and V_6 occurs once in V_3 (x) V_3,
so iota_6(B_6(u)) = c_1 iota_3(u)^2 with c_1 nonzero. The Jacobian J(f,g) = f_x g_y - f_y g_x
satisfies J(f o A, g o A) = det(A) J(f,g) o A, so it is SL(2)-equivariant. It is bilinear, maps
degrees (12, 6) to degree 16, and is nonzero (J(x^12, y^6) = 72 x^11 y^5). V_8 occurs once in
V_6 (x) V_3, so [X (x) Y]_8 = c_2 iota_8^(-1) J(iota_6 X, iota_3 Y) with c_2 nonzero. Hence
iota_8(C_0(u)) = c J(F^2, G) with c nonzero, where F = iota_3(u) and G = iota_3(Theta u).
Computed confirmation, an exact identity in u and conj u:
iota_8^(-1) J(F^2, G) = 504 sqrt286 C_0(u), all 17 components.

2. *Leibniz.* J(F^2, G) = 2 F J(F, G) (also checked symbolically). u is nonzero and iota is
injective, so F is a nonzero element of the integral domain C[x,y]. Therefore C_0(u) = 0 iff
J(F, G) = 0.

3. *Classical fact.* G is nonzero because Theta is injective. F and G are nonzero binary forms of
the same degree 6 > 0 over C. By the supplied classical fact, J(F,G) = 0 implies G = lambda F for
some lambda in C. iota is linear and injective, so Theta u = lambda u, and |lambda| = 1 because
||Theta u|| = ||u||. Conversely, Theta u = lambda u gives G = lambda F and
J(F,G) = lambda J(F,F) = 0.

4. *Shape of the set.* If Theta u = lambda u with lambda = e^(-2it), then a = e^(-it) u satisfies
Theta a = e^(it) lambda u = a. So the zero set is U(1) Fix(Theta) minus {0}, where
Fix(Theta) = {u : u_(-m) = (-1)^m conj(u_m)} is a real 7-dimensional subspace (u_0 real). The zero
set is a real 8-dimensional cone; projectively it is the real locus RP^6 of the real structure
Theta on CP^6. The constellation statement is the equivalence of Section 2.2. QED.

Exact illustrations: C is identically 0 on the 7-parameter family Fix(Theta).
C(lambda u) = lambda^2 conj(lambda) C(u). ||C(u)||^2/||u||^6 = 0 at v_0, the octahedra and the
hexagon, and equals 1/1092 at v_3, 1422/11375 at the item-8 ray and 1895200/21705411 at the item-9
prism. All of these agree with the theorem.

## Item 21: derivation

psi psi^T(g) = u^T D(g) eta eta^T D(g)^T u, and psi psi^T(gh) = psi(g) sigma(h) sigma(h)^T psi(g)^T.
As u varies, psi(g) ranges over all of C^d. So |psi psi^T|^2 is Gamma-invariant iff
|x S x^T| = |x x^T| for every row x, with S = sigma sigma^T symmetric. The ratio of these two
holomorphic quadratics has constant modulus on a dense connected open set, so it is a constant
lambda(h), giving S = lambda(h) I. lambda is a character of Gamma, and Gamma is perfect (item 0),
so lambda = 1. Then sigma unitary with sigma sigma^T = I forces sigma = conj(sigma): sigma must be
real orthogonal in the basis carried by eta. That is possible iff sigma is of real type. Both
level-6 summands have FS = +1. I built the basis explicitly: Theta commutes with P and Theta^2 = +1,
and a Theta-fixed orthonormal eta exists. Exact checks: sigma(q1) and sigma(q2) are real
orthogonal, psi psi^T is right-invariant, and with a non-real basis eta diag(1, i, 1, ...) both
fail.

The CG series without conjugation gives psi psi^T = sum_J B_J(u)^T D^J(g) R'_J with
R'_J = sum <3n;3n'|JN> (eta eta^T)_(nn'). The left factor is the holomorphic square
B_J(u) = [u (x) u]_J = M_J(u (Theta u)^dag): the same transform applied to u (Theta u)^dag instead of
u u^dag (exact identity). It vanishes for odd J. With Theta eta = eta, (eta eta^T)_(nn') =
(-1)^n' P_(n,-n'), so R'_J = M_J(P) = R_J (exact). The nonlinearity is
d|psi psi^T|^2/d conj(psi) = 2 (psi psi^T) conj(psi), and conj(psi_u) = psi_(Theta u). Projecting
to level 6 exactly as in item 14 gives N'(u) = (1/d) sum_J c_J N_J(u), where
N_J(u) = [B_J(u) (x) Theta u]_3 and the c_J are the same as in item 14 (FLOAT quadrature agreement
5e-14). The filter keeps J even (B_J nonzero) with R_J nonzero (item 10), so J is in {0, 6}. The
span is span{N_0, N_6}, of dimension 2 (exact). It does not coincide with span{M_0, M_6}: the
exact rank of {M_0, M_6, N_0, N_6} is 4.
